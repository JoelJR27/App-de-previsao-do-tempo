## Português

> Status: Finalizado ✅

**CloudVision** é um app de previsão do tempo, desenvolvido por mim, com uma interface amigável aos usuários e que permite com apenas alguns cliques checar as temperaturas mínima e máxima atuais além de outras métricas.

## Principais funcionalidades

- Manipulação do DOM
- Aplicação de estilos CSS com base em ações do usuário
- Exibição dinâmica ao usuário de dados recebidos da [OpenWeather API](https://openweathermap.org/api)
